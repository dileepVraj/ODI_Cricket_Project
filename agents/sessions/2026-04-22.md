## Addendum - Match Setup Draft Save

### What was done
- Added draft saving for Cockpit trades so the Match Setup form can save pre-toss data first and finish later.
- Added a `status` field to cockpit trade records and kept the toss fields nullable.
- Added a patch route so a saved draft can be loaded back and updated in place.
- Added a visible `Pending Pre-Toss Trades` panel on the live trade screen.
- Updated the Match Setup button text to switch between `Save Pre-Toss` and `Execute Trade`.

### What was decided
- Drafts stay out of history totals and summary counts by filtering those views to `ACTIVE` trades only.
- A loaded draft keeps the same trade id when it is completed, so the user can finish the same record instead of creating a new one.
