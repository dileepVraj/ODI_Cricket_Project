## PROJECT OVERVIEW

**Cricket Algo-Trader**: A data-driven cricket match analysis platform with:
- **Backend**: Python (FastAPI) with headless engines (TeamEngine, PlayerEngine, PredictorEngine)  
- **Frontend**: Next.js 16 + React 19 + Tailwind CSS
- **Architecture**: Manifest-driven — the ODI manifest (`formats/odi/manifest.py`) defines ALL categories, functions, context fields, and output types. The frontend reads the manifest and dynamically builds the entire UI.

## CRITICAL RULES (FROM GEMINI.md)

1. **Manifest is Law** — NEVER hardcode sidebar items or screens in React. Everything comes from manifest.
2. **No Format-Specific Frontend Code** — NEVER write `if (format === 'odi')` in React.
3. **Don't Touch the Engines** — Engines are STABLE. Fix mismatches in `api/main.py` or `api/serializers.py`.
4. **Update AI_MEMORY.md** — After EVERY significant task, update session history.
5. **No Lazy Placeholders** — Never use `// ... rest of code remains the same`. Full output always.
6. **Defensive Data** — Always check `if col in df.columns`, safe division `a / b if b > 0 else 0`.
